## Findings and minimal adaptation

- No business tools, provider choices, call fields or required fields are added or removed. Search result count defaults to 5, workflow to none and fetch mode to readable. Dependency and peer ranges are unchanged. Configuration additions do not belong in the constant op/input schema or tool-argument help.
- New resolveProviderApiUrl replaces the official origin with a configured provider base, preserves a gateway prefix, and appends the official endpoint path/query. Matching environment variables override config. DeepSeek and Ollama use PI_DEEPSEEK_BASE_URL and PI_OLLAMA_BASE_URL; bare names are ignored. Jina and Mistral use jinaSearch/mistralSearch stems. Shared validation allows HTTPS or loopback HTTP, disallows URL credentials/query/fragment, and trims trailing slashes. Official defaults are retained.
- Reviewed representative integrations: DeepSeek search and opted-in hosted fetch share the override; SerpApi uses /search.json with query api_key; Jina appends the encoded query and rejects standalone dot path segments. The changelog and upstream coverage table describe migration of additional providers; this candidate does not independently test every provider.
- Credential redirect helper already limited calls to five redirects and stripped configured credential headers across origins. It now also accepts credential query parameter names; SerpApi passes api_key, deleting every occurrence from a cross-origin destination and excluding it from redirect-limit errors. Method/body rewrite rules for 301/302 POST and 303 remain; 307 preserves method/body. This differs from the existing page-fetch same-origin refusal policy and must not be described as blocking all cross-origin redirects.
- New toolActivation=none requires toolExposure=deferred and skips upstream loader registration. Native upstream expects codemode/tool_search access. The lean adapter still creates a direct web_access tool without inheriting upstream exposure; it already drops web_enable and suppresses setActiveTools. Document that boundary, preserving the original lean rule and tool identity. Defaults remain auto/direct, and deferred/eager remains invalid.
- Existing default-name routes, five-argument execute forwarding, prepareArguments array normalization and independent local PDF handling remain compatible. Read the complete local adapter; no source edit is needed. Results are returned literally. search structuredContent contains results/snippets; fetch structuredContent.urls[].content contains body data; rendered text can include titles and retrieval/storage hints. These layers must be asserted independently.

English and Chinese package READMEs now describe current gateway settings, environment precedence, URL constraints, redirects, Jina query rejection and the none/deferred boundary. Corrected their stale runtime-version line to 0.44.0. Package MAINTENANCE records the detailed review. Existing user documentation remains current usage, without upgrade logs. The fixed check updates wrapper versions and measured documentation.
