## Web compatibility

Compared before/after changelogs and package metadata, index initialization and search/check/fetch/get registration/execution boundaries, gemini-search provider tables, utils proxy configuration/selection, and github-extract default directory and README rendering. Read both new providers in full and the web-tool-contract response definitions. This is a facade compatibility review, not a complete upstream security audit.

No tools, call fields, required fields or schema types are added/removed; search default count 5, workflow none and fetch readable remain. Dependency and peer ranges are unchanged. Sofya and Outcrawl join the allowed-provider discovery list automatically through existing on-demand help. JSON input delegates them without expanding the permanent op/input schema. Both are explicit/configured-route providers and excluded from the default auto/all set. Sofya uses snippets depth, include/exclude_domains (10 each), freshness and a maximum 20 results; Outcrawl builds site clauses, requests up to five extra results under filtering (cap 20), and ignores recency. lockProxy is an opt-in configuration field, not a new tool parameter. runWithProxy now reads and validates proxy configuration even for an explicit override. Existing loopback/metadata/NO_PROXY transport bypasses remain: do not describe this as universal traffic confinement. Local PDF extraction is a separate branch. Upstream proxy help now recommends omission and is disclosed as-is.

GitHub clone defaults use os.tmpdir() instead of /tmp; configured clonePath wins. Cloned root README text increases from 8192 to 100000 characters; rendered replies still obey the inline cap and can be continued through get. No clone implementation is copied. Keep local PDF Markdown/counters, default-name routing, five-argument execute, prepareArguments delegation, legacy provider-string-array normalization, web_enable suppression and active-list interception. Search structured results are snippets, fetch urls[].content is stored content, and rendered text includes presentation/retrieval hints. New upstream-047 regression covers real-facade provider help/JSON requests/filtering/structured snippets and proxy-lock rejection for search/check/fetch. DNS and fetch are mocked before imports, all URLs are absolute HTTPS, keys are fictional, and unexpected targets throw.
